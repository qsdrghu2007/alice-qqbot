# 拟人化 15 项验收矩阵

本文件只记录当前实现的行为和可复核证据。运行层证据来自 Node 测试；语气、长度、自然程度最终仍受真实模型影响，不能由静态测试保证每次生成都完全符合。

共同约束：

- 缓存：静态 system 前缀、历史、最后一条动态 user 保持分离；画像、ACL 上下文、记忆和表情状态只进入最后一条 user。
- 隔离：消息历史、消息合并、发送队列和回访状态仍按实际会话；跨场景共享只经过 `ConversationState.visibleContext()` 的安全画像与来源 ACL。
- 审校：只发送当前用户的安全化历史表示、草稿和无原文数字/布尔习惯统计。纯文字保持原样；附件用去除 URL、路径、令牌和媒体数据并限长的文本摘要；状态与计数只在同一 sender-aware ACL context 的实际提交态更新。
- 全局情绪不保存账号、原文或原因；用户情绪是独立的上下文状态，不镜像成全局情绪。

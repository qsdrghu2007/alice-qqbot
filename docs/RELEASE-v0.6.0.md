# Alice v0.6.0 发布说明

本版本集中完善 WebUI 设置生效链路、自然群聊、长期记忆、空间任务和文件写入行为。发布包只包含源码、测试、脚本和文档，不包含运行数据、NapCat、`node_modules`、备份或密钥。

## 升级

- 从 v0.5.0 升级前先备份 `data/`。
- 替换源码后执行 `npm ci`，再完整重启一次 Alice，让后端配置结构和新增模块生效；浏览器随后刷新一次控制台。
- Node.js 要求仍为 22 或更高版本。
- NapCat 不在发布包内。请从 [NapCat 官方 Release](https://github.com/NapNeko/NapCatQQ/releases) 获取并单独安装；Windows 便携 Shell 目录中的 `NapCatWinBootMain.exe` 用作启动入口，`napcat.bat` 保留可选的命令行启动方式。按 README 的目录约定放到 `napcat/NapCat.52230.Shell` 后，可在项目根目录双击 `start.bat` / `start-onebot.bat` 分别启动 Alice 和 NapCat。macOS 从项目根目录运行 `npm start` 或 `start.command`，NapCat 按官方方式单独启动。

## 主要变更

- 控制台顶部增加清晰的运行模式按钮。`runtimeMode` 支持 `auto`、`basic`、`full`；显式 `basic` / `full` 优先，`auto` 读取 `ALICE_RUNTIME_MODE`，环境变量也未指定时按基础模式运行。基础模式只临时关闭空间发布/评论、定时发帖、表情库、主动回访等高级能力，设置表单仍可保存，切回完整模式后恢复。
- WebUI 保存的人格名称、System Prompt、稳定喜好/观点和思考强度会进入后续轮次。上传与导入统一使用 MiB 精度，导入硬限制为 10 MiB；表情图片按解码后单图 8 MiB 上限检查，JSON/base64 请求体还会包含编码开销。
- 群聊主设置改为 `enabled`、`allowUnprompted` 和 `activityLevel`。明确 @、多 @、当前人格名和引用 bot 都是强信号；普通插话依据近期消息、发言人数、群记忆、兴趣和关系评分，并分别使用普通主动、续聊和总主动预算。
- 群聊等待按近期活动窗口、发言人数和积极度调整，不再使用固定群人数公式。普通插话允许沉默，连续回复或无人接话后进入退场冷却；明确召唤与自然参与路径分离。
- 群聊的非点名结构化 JSON 决策只用于候选动作，不会把内部 JSON 规则混入正常明确回复。明确回复使用当前群有限现场、发言人和引用对象，并沿用审校、工具、联网搜索及长期记忆链路。
- 群聊 JSON 历史保留 `speakerId` 与消息时间；后续注入和回忆结果保留说话人归属。群长期记忆按群共享，群回忆搜索默认 24 小时并可在 WebUI 调整，私聊回忆仍固定最近 7 天。
- `ai.historyMessages` 默认 30 的语义是已提交的 user/assistant 消息条数，`user` 与 `assistant` 分别计条；普通非点名群现场只在本轮动态上下文，不写入该历史。
- 私聊和明确群聊使用同一套 `web_search` / `web_fetch` 判断规则；普通非点名群候选不开放工具。搜索失败或没找到时不编造结果。
- 私聊纯 ACK 由 AI 结合少量近期上下文判断是否收尾，不再只靠离线白名单；失败时继续回复。连续消息合并等待可由 WebUI 热更新，闲置会话状态按 TTL 和容量修剪。
- `store` 中的聊天历史与长期记忆减少全量复制和高频写盘，待写内容合并后原子落盘；容量与 TTL 修剪继续生效。
- 空间自主发布统一由 `qzone.autoPublish` 控制，手动明确发布只受空间能力、权限和策略控制。自主发帖允许 AI 判断本次不发布；内容仅使用严格限定的近期素材与可见范围。
- 空间评论与聊天共用人格前缀；评论使用同楼层有限前后文，再由独立 AI 判断是否值得回复，低质评论可跳过。楼中楼失败仍默认不回退，Cookie 只保存在内存。
- 上下文保持静态 system、可选画像 system、历史和最后动态 user 的缓存友好布局；人格稳定项与群规则用于稳定前缀，记忆、表情、群现场和当前消息只在动态尾部。

## 验证

- 发布目录 `npm test`：384 项通过，0 跳过，0 失败。
- `npm run check`、`node --check public/app.js` 与发布候选文件检查按发布流程完成。
- 这些自动化结果证明代码路径和静态约束按测试工作；没有用真实 QQ 账号和真实模型完成端到端验收。NapCat 版本、QQ 风控、网页版空间协议、模型输出和真实群语境仍可能造成差异，上线后应先小范围验证。

## 已知边界

- 群聊自然参与是启发式候选加模型判断，不能保证每次都识别隐含话题、选择沉默或语气自然。
- 群长期记忆由群成员共同影响，不适合保存成员私密内容；网页导出与备份仍需按本机敏感数据处理。
- 空间评论依赖网页版 QZone 协议，接口和风控可能变化，建议先保持 `dryRun` 观察。
- 搜索结果不做语义二次筛选；关键词回忆也可能漏召回。
